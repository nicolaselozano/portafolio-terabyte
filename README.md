# Terabyte · Portafolio grupal

Portafolio web del grupo **Terabyte** de la materia *Programación 2*. Una página estática que presenta al equipo, sus roles, habilidades y medios de contacto.

**Enlace de despliegue:** <https://portafolio-terabyte.onrender.com>

## Secciones

- **Inicio** — presentación general del grupo.
- **Miembro destacado** — carrusel con el perfil, la bio y las habilidades de cada integrante, con autoplay.
- **Equipo** — grilla con los cinco integrantes; al hacer clic se destaca el perfil correspondiente.
- **Contacto** — correo, LinkedIn y GitHub del grupo.

## Tecnologías

- HTML5
- CSS3
- JavaScript (vanilla, sin frameworks)
